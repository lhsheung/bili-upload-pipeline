# 哔哩哔哩投稿流水线

> 作者：[@lhsheung](https://github.com/lhsheung)（LauHingSheung）

把 B 站投稿页变成一条批量入库流水线：**按原视频文件名自动配封面**、批量设「仅自己可见」与创作声明、失败项自动重试、遇到 B 站限流自动退避。

面向个人备份 / 私密存档场景：视频只给自己看，B 站当仓库用，不用再为网盘空间和预览速度发愁。

## 功能

| 能力 | 说明 |
|---|---|
| 一键全部设置 | 对列表里每个待上传稿件依次设置：标题、封面、创作声明、可见范围、空间隐藏等 |
| 封面按原名匹配 | 只认「原视频文件名」，不做相似度猜测；同名多图时优先选 16:9 |
| 失败自动重试 | 第一轮没成功的项自动补一轮，只补失败的，不重跑已成功的 |
| 限流自动退避 | 页面出现「请求频率过高」时自动暂停 2.5s，仍在限流再等 6s |
| 批量立即投稿 | 逐项点击「立即投稿」，含一次性确认弹窗 |
| 单项操作 | 仅标题 / 仅封面 / 仅声明 / 仅隐私 / 仅标签，可单独跑 |

## 安装

1. Edge 安装 [Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)（或 Violentmonkey）
2. 打开扩展管理页 → 新建脚本 → 粘贴 `bili-upload-pipeline-1.1.user.js` 全部内容 → 保存
3. 打开 `https://member.bilibili.com/platform/upload/video/`，右下角出现面板即生效

> 同一浏览器里只保留一份本脚本。旧版本（如「B站批量投稿设置助手」）请先删除或禁用，否则两套脚本会在同一页面重复操作。

## 使用流程

1. 批量上传视频，等列表里出现待上传任务
2. 面板里选封面来源 → **按文件名匹配** → 选图片（多选）或选文件夹
3. 面板会列出「视频 → 封面」，`原名✓` 为精确命中，`未匹配` 可用下拉手动改绑
4. 点「一键全部设置」
5. 核对日志后，点「批量立即投稿」

## 封面匹配规则

匹配只做三件事：去路径、去扩展名、统一小写与全角/半角。

- `课程A_20251109.mp4` ↔ `课程A_20251109.jpg` → ✅ 命中
- `课程 第01讲.mp4` ↔ `课程第01讲.jpg`（少一个空格）→ ❌ 不命中，不猜
- `课程C_215.mp4` ↔ `课程C_216.jpg`（差一位数字）→ ❌ 不命中，不猜
- 同一文件名下存在 16:9 与 4:3 两张 → 优先 16:9（B 站封面位是 16:9）

配不上不是错配，面板会明确标「未匹配」，手动绑一次即可。这样永远不会把 A 的图贴到 B 上。

## 限流

B 站对频繁请求会提示「请求频率过高」。面板里有「**限流时自动暂停（默认关）**」开关：

- **默认关闭**：命中提示也不暂停，保持原速
- **打开后**：命中即暂停 2.5 秒；仍在限流再停 6 秒，日志会写 `[限流] B站提示「…」→ 暂停 2.5s`

无论开关状态，每项之间默认留 0.8 秒间隔。想进一步降低请求量：面板里只勾真正要设置的项目。

## 配置

脚本顶部 `CONFIG`：

```js
const CONFIG = {
  DECLARATION_TEXT: '内容无需标注',
  PRIVACY_TEXT: '仅自己可见',
  DELAY_BETWEEN_TASKS: 800,   // 每项间隔，太短会触发限流
  DELAY_AFTER_CLICK: 120,
};
```
