# 哔哩哔哩投稿流水线

> 作者：[@lhsheung](https://github.com/lhsheung)（LauHingSheung）

把 B 站投稿页变成一条批量入库流水线：**按原视频文件名自动配封面**、批量设「仅自己可见」与创作声明、失败项自动重试。

主要为 **PS5 游戏视频备份** 而写：PS5 录像动辄几个 GB，硬盘很快见底；传到 B 站设为「仅自己可见」，等于给自己开了一个不限速、带倍速和 AI 字幕的私人视频库，手机、平板、电脑随时能翻。

## PS5 游戏视频备份

PS5 的录像和截图是同一套命名：`游戏名_日期时间`，两者只差扩展名。这正是「按原名匹配」最理想的输入——**不用改任何文件名**。

| 视频（PS5 录像） | 封面（PS5 截图，放同一文件夹） | 匹配结果 |
|---|---|---|
| `跑车浪漫旅 7_20251109124745.mp4` | `跑车浪漫旅 7_20251109124745.png` | ✅ 原名✓ |
| `地平线 西之绝境_20251110183012.mp4` | `地平线 西之绝境_20251110183012.png` | ✅ 原名✓ |
| `死亡搁浅 2_20251112194533.mp4` | 只有 `死亡搁浅 2_20251112194534.png`（差 1 秒） | ❌ 未匹配，手动绑 |

流程：

1. PS5 把录像导出到 U 盘（`PS5/VIDEO/`），截图在（`PS5/PHOTO/`）
2. 在 B 站投稿页批量上传这些 mp4
3. 把要当封面的截图（或自己裁好的 16:9 图）放进一个文件夹，文件名保持与视频一致
4. 面板 → 封面来源选「按文件名匹配」→ 点「选文件夹」，把整个文件夹选进来
5. 面板会逐行显示 `视频名 → 封面名（1920×1080）`，`原名✓` 就是精确命中
6. 可见范围选「仅自己可见」，点「一键全部设置」
7. 核对日志里没有 `✗`，再点「批量立即投稿」

> PS5 截图原生 3840×2160，本身就是 16:9，正好等于 B 站封面位比例，不会被裁。
> 若一个视频有多张候选封面（比如 16:9 和 4:3 各一张、**文件名相同**），脚本优先挑 16:9，并在日志写 `[同名 2 张] 选 xxx（1920×1080）`。

## 功能

| 能力 | 说明 |
|---|---|
| 一键全部设置 | 对列表里每个待上传稿件依次设置：标题、封面、创作声明、可见范围、空间隐藏等 |
| 封面按原名匹配 | 只认「原视频文件名」，不做相似度猜测；同名多图时优先选 16:9 |
| 失败自动重试 | 第一轮没成功的项自动补一轮，只补失败的，不重跑已成功的 |
| 限流自动暂停（可选） | 面板开关，**默认关**；打开后遇「请求频率过高」暂停 2.5s，仍在限流再等 6s |
| 批量立即投稿 | 逐项点击「立即投稿」，含一次性确认弹窗 |
| 单项操作 | 仅标题 / 仅封面 / 仅声明 / 仅隐私 / 仅标签，可单独跑 |

## 安装

1. Edge 安装 [Tampermonkey](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)（或 Violentmonkey）
2. **推荐**：直接打开 raw 链接，Tampermonkey 会弹出安装页
   `https://raw.githubusercontent.com/lhsheung/bili-upload-pipeline/main/bili-upload-pipeline-1.1.user.js`
   或者：扩展管理页 → 新建脚本 → 粘贴 `bili-upload-pipeline-1.1.user.js` 全部内容 → 保存
3. 打开 `https://member.bilibili.com/platform/upload/video/`，右下角出现面板即生效

> 同一浏览器里只保留一份本脚本。旧版本（如「B站批量投稿设置助手」）请先删除或禁用，否则两套脚本会在同一页面重复操作。

## 使用流程

1. 批量上传视频，等列表里出现待上传任务
2. 面板里选封面来源 → **按文件名匹配** → 选图片（多选）或选文件夹
3. 面板会列出「视频 → 封面」，`原名✓` 为精确命中，`未匹配` 可用下拉手动改绑
4. 点「一键全部设置」
5. 核对日志后，点「批量立即投稿」

## 封面匹配规则

匹配只做三件事：**去路径、去扩展名、统一小写与全角/半角**。空格、下划线、括号、`(1)` 副本号一律原样保留——它们本身就是文件名的一部分。

为什么不做「相似度匹配」：`死亡搁浅 2_194533` 和 `死亡搁浅 2_194534` 只差一位数字，相似度高达 95%，任何阈值都会把它们判成同一张，结果就是 A 的图贴到 B 上。宁可标「未匹配」让你手动绑一次，也不猜。

- `跑车浪漫旅 7_20251109124745.mp4` ↔ `跑车浪漫旅 7_20251109124745.png` → ✅ 命中
- `跑车浪漫旅 7_20251109124745.mp4` ↔ `跑车浪漫旅 7_20251109124545.png`（时间差 2 分钟）→ ❌ 不命中，不猜
- `课程 第01讲.mp4` ↔ `课程第01讲.jpg`（少一个空格）→ ❌ 不命中，不猜
- 同名存在 16:9 与 4:3 两张 → 优先 16:9（B 站封面位是 16:9）

配不上不等于配错：面板会明确标「未匹配」，下拉里手动选一次即可。这样永远不会把 A 的图贴到 B 上。

## 限流

B 站对频繁请求会提示「请求频率过高」。面板里有「**限流时自动暂停（默认关）**」开关：

- **默认关闭**：命中提示也不暂停，保持原速
- **打开后**：命中即暂停 2.5 秒；仍在限流再停 6 秒，日志会写 `[限流] B站提示「…」→ 暂停 2.5s`

无论开关状态，每项之间默认留 0.8 秒间隔。想进一步降低请求量：面板里只勾真正要设置的项目。

## 配置

脚本顶部 `CONFIG`：

```js
const CONFIG = {
  DECLARATION_TEXT: '内容无需标注',
  PRIVACY_TEXT: '仅自己可见',
  DELAY_BETWEEN_TASKS: 800,   // 每项间隔，太短会触发限流
  DELAY_AFTER_CLICK: 120,
};
```
